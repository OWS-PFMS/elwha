Elwha

Elwha is a Swing component library built on FlatLaf, implementing Material 3 Expressive as a design system for desktop Java: a design-token foundation plus the component catalog and the containers, overlays, and anchors around it. Runtime dependencies are Swing + FlatLaf only.

Quick start

Install the theme once, before building UI; every component resolves its tokens at paint time, so a later theme or light/dark switch re-skins the running UI live:

{@code
ElwhaTheme.install(
    ElwhaTheme.config()
        .theme(MaterialPalettes.baseline())
        .mode(Mode.SYSTEM)
        .build());

ElwhaButton save = ElwhaButton.filledButton("Save");
ElwhaSwitch wifi = new ElwhaSwitch(true);
}

Start at {@link com.owspfm.elwha.theme} — the token vocabulary ({@link com.owspfm.elwha.theme.ColorRole}, {@link com.owspfm.elwha.theme.ShapeScale}, {@link com.owspfm.elwha.theme.SpaceScale}, {@link com.owspfm.elwha.theme.TypeRole}, {@link com.owspfm.elwha.theme.StateLayer}) is how every component documents its bindings.

Conventions worth knowing

  • Anchors: badges and FABs attach to hosts through dedicated anchor primitives ({@link com.owspfm.elwha.badge.ElwhaBadgeAnchor}, {@link com.owspfm.elwha.fab.ElwhaFabAnchor}) rather than subclassing.
  • Elevation: every shadowed primitive reserves halo space and exposes it via {@link com.owspfm.elwha.theme.ShadowBearing#getShadowInsets()}.
  • Motion: shared engines in {@link com.owspfm.elwha.theme} (ripple, shape morph, content morph); the global {@link com.owspfm.elwha.theme.MorphAnimator#setReducedMotion(boolean) reduced-motion switch} snaps everything.
  • Icons: use {@link com.owspfm.elwha.icons.MaterialIcons}, never raw {@code FlatSVGIcon} — house cut is Material Symbols Rounded / 400 / fill 0.

Design rationale per component lives in the repository's docs/research design documents; development conventions in docs/development.
